# Tucano discussion #52 — design studies

Seven static design mockups, prepared November 10, 2026. Recommendation: focused threads. Alternative: inline threads. Workspace, channel context and reply intent are shared proposals.

See [proposal.md](proposal.md) for the full handoff, sources, behavior and validation limits.

Open mockups.html with `?view=a`, `?view=b`, `?view=workspace`, `?view=context`, or `?view=replies`; `&theme=dark` selects the dark study. This is a static illustration, not an app implementation. Controls are visual specimens. Use Playwright and installed Chrome to run capture.mjs.

Reference assets: public Tucano channel screenshot at eduwxyz/tucano@95e6b62; quoted-reply screenshot from marcelogrcia/tucano@aed5240; work-drawer screenshot from apoapostolov/tucano@a977fa8. Avatar crops and icon paths are reused from Tucano for visual continuity; Tucano is Apache-2.0 (repository LICENSE). The HTML uses Inter via jsDelivr/@fontsource-variable/inter (SIL OFL-1.1). No original application behavior was modified.

All text, names, counts and code in mockups are illustrative. Capture report checks horizontal bounds only; behavior, screen reader support, zoom and core enforcement are not validated by these static studies.
